# 1.0 路線圖

> 這份記 desk 走到 1.0 的方向：終點、已經決定的、還說不清楚的、不做的。每版實際改了什麼看 [CHANGELOG](../CHANGELOG.md)；面板用語的定義看 [詞彙表](../GLOSSARY.md)。

## 終點

- 給外部使用者用：沒參與開發的人照 README 就能裝好、開第一張卡、走完六段。
- 面板雙語：繁體中文預設，加上英文介面；文件跟著有英文版。
- 公開介面凍結：指令、卡片格式與設定鍵在 1.0 定下來，之後改動要相容舊版，並有守門測試鎖住。

## 還說不清楚的

- 英文版：英文介面要拆幾版、文件的英文版跟介面同一版或之後補，還沒定。
- 示範資料英文：教學沙盒的示範卡與示範資料要不要跟著翻、在哪一版翻。
- 面板路線圖卡：要不要在面板放一張唯讀的路線圖卡，直接看這份的進度。

## 不做

- 給 Agent 的提示詞與卡片欄位名（等你、關卡、檢查這些 DESK 區塊欄位）不翻成英文：它們是解析契約，翻了舊卡就讀不到。
- 1.0 之前不再調整審查政策（修正輪數、MEDIUM 規則、常犯錯誤清單的讀法），只修 bug。
